How It Works

Step 1: Set Up Your Sync

Select source and target folders or drives. Use the Simple Scheduling Assistant for quick setups like Indexed Weekly, or advanced options like Yearly recurrences.

Step 2: Configure Schedule and Alerts

Define triggers with time delays or launch events. Customize notifications and enable Security Scope tests to monitor access integrity.

Step 3: Run and Monitor

Launch syncs manually or automatically. Track progress in the Organizer Window, sorted by next run, with detailed logs and path reveals.

Step 4: Review and Refine

Check verbose task descriptions and popovers. Adjust via the enhanced manager—everything stays precise and under control.
